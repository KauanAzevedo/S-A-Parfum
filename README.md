# Conceito Barber Shop

Site institucional da Conceito Barber Shop, em São João Batista/SC.

## Conteúdo

- Página inicial
- História da Conceito
- Equipe
- Serviços e preços
- Produtos
- Galeria
- Contato direto pelo WhatsApp
- Políticas institucionais

O projeto não possui login, cadastro, agendamento, painel administrativo ou banco de dados. As informações institucionais ficam versionadas junto ao código do site.

## Desenvolvimento

```bash
pnpm install
pnpm dev
```

## Validação

```bash
pnpm test
pnpm build
```
